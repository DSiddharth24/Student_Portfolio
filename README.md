# Student Portfolio

A clean, responsive personal portfolio website built with vanilla HTML, CSS, and JavaScript — no frameworks or dependencies required.

## Live Preview

Open `index.html` in any modern browser to view the portfolio locally.

---

## Features

- **Typed / rotating hero text** — cycles through role titles with a typewriter effect
- **Sticky navbar** — shrinks on scroll with an active-section indicator
- **Hamburger menu** — collapsible mobile navigation
- **Scroll-reveal animations** — cards and sections fade in as they enter the viewport
- **Animated skill bars** — progress bars animate when scrolled into view
- **Project filter tabs** — filter projects by category (Web / Python / All)
- **Contact form** — client-side validation with simulated submission feedback
- **Back-to-top button** — appears after scrolling 500px, smooth-scrolls to the top
- **Fully responsive** — tested at 480px, 768px, and 900px+ breakpoints
